# Profile Photo Instructions

Place your portrait photo in this directory with the exact filename:

```
assets/profile.jpg
```

### Guidelines for best presentation:
- **Aspect Ratio**: Portrait (approx. 4:5 or 3:4).
- **Resolution**: At least 600 × 750 pixels (or higher).
- **Framing**: The website automatically applies `object-fit: cover` and `object-position: top center` to ensure your head and face remain centered and are never clipped.
